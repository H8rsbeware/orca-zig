# Orca

An experiment into custom databasing, compression, and alignment.

This is my first (real) Zig repo and dive into low level programming.

## Declaration

This repo makes no use of AI generated code, comments, or any other content. This is a learning
repository.

For this reason, I have decided to comment more frequently, and in a more conversation manor, since I want to convey my understanding and decisions to any readers.

Some AI has been used, external to the repo, for learning purposes - this includes:

- Explaining concepts of low level code
- Parsing Zig documentation, where necessary
- As a rubber duck, for discussing my implementations

## Goals

1. Custom database format (including headers, paging, etc) specific to genetic sequence types
2. Optimised pipelines, focusing on binary maths and representation
3. Understand Zig compile time code, especially for creating custom encoders
